# 🔐 FrostLogin UI

Uma interface moderna de autenticação desenvolvida com foco em simplicidade, elegância e experiência do usuário, utilizando um visual clean com cores vibrantes e elementos modernos para formulários de login.

---

## 📸 Preview do Projeto

Interface contendo:

- Formulário de login moderno
- Botões de autenticação social
- Campos de entrada estilizados
- Mensagens de validação personalizadas
- Botão principal de login
- Link para recuperação de senha
- Área para cadastro de novos usuários

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Layout moderno e minimalista
- Gradiente em tons de roxo
- Bordas arredondadas suaves
- Interface centralizada
- Campos estilizados com feedback visual
- Mensagens de erro personalizadas
- Botões sociais integrados
- Design responsivo e elegante

---

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de uma interface de autenticação moderna, explorando conceitos de formulários estilizados, validação visual e design responsivo com CSS.

---

## 📚 Funcionalidades

- Login com e-mail e senha
- Botões de login social
- Validação visual dos campos
- Recuperação de senha
- Área de cadastro para novos usuários
- Estrutura adaptável para diferentes dispositivos
